# P1 Closure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the remaining P1 gaps in news degradation, structured fallback propagation, and fundamentals snapshot correctness.

**Architecture:** Preserve existing public interfaces while making failure information explicit at the seams. Vendor routing retains typed rate-limit failures and exposes a source-aware result for the snapshot builder; LangGraph nodes propagate fallback state through returned updates; fundamentals snapshots carry signed metrics and provenance and reject metadata-only results.

**Tech Stack:** Python 3.12, LangGraph, LangChain tools, Pydantic, pytest, Ruff.

## Global Constraints

- Use `uv run python` for Python execution and `uv run python -m pytest` for tests.
- Use `uv pip install` for package installation; no dependency installation is expected.
- Preserve existing callers of `route_to_vendor()` and existing fallback markers/checkpoints.
- Do not commit automatically in the shared dirty worktree.
